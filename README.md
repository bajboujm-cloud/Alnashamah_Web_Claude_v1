# Al Nashamah (النشامى) — Livestock Trading Web App

Bilingual (English / Arabic) e-commerce web app for ordering sheep and goats in the UAE, to be extended
into a mobile app later.

| File | What it is |
|---|---|
| `docs/MASTER_PROMPT.md` | Ready-made prompt to paste into Claude Code to build the app |
| `docs/SETUP_GUIDE.md` | What to install, which accounts to create, how to connect them |
| `.claude/skills/nashamah-brand/SKILL.md` | Brand/taste skill (colors, fonts, RTL, logo rules) used by Claude |
| `docs/brand/` | Brand kit PDF and logo |

Stack: Next.js + React + TypeScript · Vercel · Neon Postgres · Vercel Blob · Stripe · Twilio Verify · Resend.
